  구현 완료 요약                                                                                                                               
  Backend (Spring Boot 3.5.10 / Java 21)                                                                                                    
                                                                                                                                            
  - 엔티티: User, Destination, NavigationSession
  - API 컨트롤러:
    - NavigationController - /navigation/route, /navigation/reroute 엔드포인트
    - DestinationController - /destinations/search 엔드포인트
  - 서비스: NavigationService, DestinationService
  - 외부 연동:
    - OsrmClient - OSRM 라우팅 엔진 연동 (한국어 안내 메시지 생성)
    - NominatimClient - OSM 기반 장소 검색
  - DB 마이그레이션: Flyway를 통한 스키마 관리

  Android (Kotlin / Jetpack Compose)

  - 위치 서비스:
    - LocationService - FusedLocationProvider 기반 위치 추적
    - GeospatialService - ARCore Geospatial API 연동
    - LocationFusionService - GPS + Geospatial 위치 융합
    - RouteDeviationDetector - 15m 이탈 시 감지
  - 음성 서비스:
    - TextToSpeechService - 한국어 TTS
    - SpeechRecognitionService - 한국어 음성 인식
  - Use Cases: StartNavigationUseCase, RerouteUseCase, SearchDestinationUseCase
  - UI: NavigationScreen (검색/네비게이션 뷰)
